Features

Tab System Multiple tabs, each with its own session. Log into the same site in two tabs with different accounts — works the way you'd expect.

Clean Design Dark interface, red accents, monospace address bar. No unnecessary buttons, no AI sidebar — just a browser that gets out of your way.

Developer Tools DevTools one click away, with fast, proper keyboard shortcuts.

Persistent Sessions Close it, reopen it, you're still logged in. No "sign back in" nonsense.

Open Source MIT-licensed. Fork it, modify it, ship it.

Just Works No setup, no account syncing, no cloud. Download, run, browse.
